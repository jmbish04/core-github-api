## 2024-06-21 - Add Accessibility and Hover Tooltips to Composer Primitive Components
**Learning:** The `@assistant-ui/react` composer primitive components (e.g., `ComposerPrimitive.Dictate`, `ComposerPrimitive.StopDictation`, `ComposerPrimitive.Send`) do not automatically generate `aria-label` or `title` attributes. When used as icon-only buttons in the UI, they become inaccessible to screen readers and lack hover tooltips for visual users. Furthermore, relying purely on mouse interactions neglects keyboard accessibility.
**Action:** When utilizing `@assistant-ui/react` primitives (or any third-party components) as icon-only interactive elements, always explicitly provide `aria-label` for screen readers and `title` for hover tooltips. Additionally, implement proper focus ring styling (e.g., `focus-visible:outline-none focus-visible:ring-2`) to ensure these elements are fully usable via keyboard navigation.
