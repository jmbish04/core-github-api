## 2026-06-15 - Improve Accessibility of Hover-Revealed Actions
**Learning:** Hover-revealed UI elements in the repository explorer (like 'Favorite' and 'Close' quick actions) can become completely inaccessible to keyboard users unless explicitly handled. Standard `group-hover:opacity-100` is insufficient for accessibility. Pairing `opacity-0 group-hover:opacity-100` with `focus-within:opacity-100` on the parent container successfully ensures keyboard users can access and interact with these elements when tabbing through the UI.
**Action:** When using `opacity-0` to hide elements until hover, always pair it with `focus-within:opacity-100` on the parent container. Also, ensure the interactive children explicitly include focus ring classes (e.g., `focus-visible:ring-1 focus-visible:ring-ring`) and appropriate `aria-label` attributes to provide full keyboard accessibility and screen reader support.
