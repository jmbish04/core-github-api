## 2025-02-12 - Added ARIA label to Chat Interface Thread Creation Button
**Learning:** Found a pattern where icon-only buttons (`<Button size="icon">` with just an icon component inside like `<Plus />`) in the UI were missing accessibility attributes. Specifically, the "Create new thread" button in the Chat Interface (`src/frontend/src/components/chat/chat-interface.tsx`) lacked both an `aria-label` for screen readers and a `title` attribute for native hover tooltips. This is a common accessibility trap that makes navigation difficult for non-sighted users and unclear for sighted users relying on hover states.
**Action:** When implementing or reviewing icon-only buttons across the application, I must ensure they always include descriptive `aria-label` and `title` attributes. I should actively scan other components using `size="icon"` buttons to apply this same accessibility standard.
